# 킹샷(Kingshot) 벤치마킹 분석

> 출처는 팬 가이드 사이트와 스토어 정보입니다. 공식 문서가 아니라서 수치(비율 등)는 사이트마다 다릅니다. 확정이 필요하면 인게임 정보로 교차 확인해야 합니다.

## 1. 한 줄 요약
Century Games의 모바일 전략 게임. 본편은 성 건설 + 영웅 + 병력 + 연맹전(4X)이고, **광고 영상은 타워디펜스/런앤건 느낌의 "존에 올라가서 돈을 내면 병력·타워가 생기는" 미니게임 형태**로 만든다.
(본편 자체는 타워디펜스가 아니다. 광고 연출은 마케팅용으로 보인다.)

## 2. 본편 전투 시스템 (참고)
| 항목 | 내용 |
|---|---|
| 병종 | 보병 / 기병 / 궁병 |
| 상성 | 보병 > 기병 > 궁병 > 보병 (가위바위보 구조, 절대적이진 않음) |
| 역할 | 보병=전열 탱커(고체력·저공격), 기병=기동 돌격 딜러, 궁병=후열 딜러 |
| 편성 비율 예시 | 랠리 50/20/30, 수비 보병 위주, 곰 사냥 10/10/80 (보병/기병/궁병, 사이트마다 상이) |
| 성장 | 영웅 레벨/스킬, 건물 업그레이드, 병력 훈련 |

## 3. 우리가 가져올 핵심: "존 → 돈 투입 → 유닛/타워 생성" 루프
맵의 정해진 위치에 **구매 존(패드)** 이 있고, 플레이어가 그 위에 서서 자원(돈)을 내면 병력 또는 타워가 생성되는 방식.

### 루프
1. 적 처치/채집으로 **돈** 획득
2. 맵의 **존**으로 이동해 위에 서 있으면 돈이 빨려 들어감 (진행 게이지)
3. 게이지가 차면 **병력/타워 생성**
4. 늘어난 병력·타워가 적 웨이브를 막고 → 더 많은 돈 → 다음 존 해금

### 존 종류 (설계안)
| 존 | 비용 | 결과 |
|---|---|---|
| 병영 존 | 소 | 병사 생성 (보병/기병/궁병 선택 가능) |
| 타워 존 | 중 | 방어 타워 설치 |
| 강화 존 | 대 | 기존 병력/타워 레벨업 |
| 확장 존 | 대 | 새 구역 해금 (새 존들 등장) |

### 이 방식이 재미있는 이유
- 입력이 이동 하나뿐이라 조작이 쉽다.
- "돈을 넣으면 눈에 보이게 커진다"는 즉각적 보상이 강하다.
- 돈을 어디에 먼저 쓸지 고르는 가벼운 전략성이 생긴다.

## 4. 반영할 전투 요소
- 3병종 상성(보병>기병>궁병>보병)을 적/아군 모두에 적용
- 적 웨이브가 마을(중앙)을 향해 몰려옴
- 타워는 고정 화력, 병력은 이동·교전
- 웨이브가 올라가면 상성이 섞인 적이 등장해 편성 판단을 강요

## 부록: 광고 영상 직접 분석 (Kingshot_Ad.mp4, 59초, 세로 576x1280)
3초 간격 프레임 20장과 확대 프레임 2장으로 분석했습니다. 소리와 프레임 사이의 움직임은 보지 못했습니다.

### 장면 흐름
| 시간대 | 장면 |
|---|---|
| 0~6초 | 구불구불한 길 + 풀밭. 길 옆에 **구매 존**(숫자+코인 아이콘) 3개(15 / 5 / 20)가 보임. 코인 0에서 시작 |
| 6~15초 | 아래쪽 길에서 **빨간 적 떼**가 줄지어 올라옴. 플레이어(왕관 쓴 기마 영웅)가 존에 서서 코인 투입 → **석궁 타워** 생성 |
| 15~45초 | 타워가 점점 늘고(1→4기), 적이 터질 때마다 **노란 코인**이 길에 쏟아짐. 존 가격은 5→15→20→25로 올라감. 큰 **갑옷 적(붉은 대검)** 이 중간중간 등장, 아군 노란 병사 무리도 길에서 교전 |
| 45~52초 | 코인 100~180 누적 → 큰 존(30) 투입 → **건물/성문 생성**, 길 입구를 막음 |
| 52~56초 | 마을 전경(집, 성, 파란 병사들)으로 전환 |
| 56~59초 | "Kingshot - **Build & Fight** - PLAY NOW!" 엔드카드 → 설치 화면 |

### 핵심 규칙 (영상에서 읽은 것)
- **화면 시점:** 위에서 내려다보는 쿼터뷰, 로우폴리, 밝은 초록 톤.
- **조작:** 플레이어는 이동만 한다. 직접 공격은 안 한다(공격은 전부 타워와 병사).
- **존:** 바닥의 점선 사각형 + `숫자 + 코인`. 올라서면 코인이 빨려 들어가 건설된다. 가격은 뒤로 갈수록 오른다.
- **코인:** 적을 잡으면 길에 코인이 흩뿌려지고, 플레이어가 지나가면 자동 획득(우상단 카운터 증가).
- **적:** 빨간 소형 몹 대량 + 갑옷 대형 몹. 한 줄로 길을 따라 이동(레인 TD 구조).
- **타워:** 석궁 타워가 파란 궤적으로 단발 저격. 맵 곳곳에 설치되어 길을 따라 사격.
- **아군:** 노란 병사 무리가 길 위에서 적과 몸싸움.
- **보상 체감:** 코인 폭죽 + 숫자 상승 + 건물이 눈앞에서 생기는 연출.

### 앞서 추정과 다른 점 (정정)
- 병종 상성(보병/기병/궁병)은 **광고에 나오지 않는다.** 상성은 본편 요소이고 광고는 적/아군 구분(빨강/노랑)만 있다.
- 광고는 자유 이동 맵이 아니라 **한 줄 길을 따라 오는 적을 막는 레인 타워디펜스**다. 마을 중앙으로 사방에서 몰려오는 구조가 아니다.
- 타워뿐 아니라 존 투입으로 **건물/성문**도 생기며, 마지막에는 마을 건설로 이어진다.

### 우리 게임에 반영할 포인트
1. 시점을 쿼터뷰(비스듬한 탑다운)로 바꾸고, 적이 지나가는 **하나의 길**을 만든다.
2. 플레이어는 이동만, 공격은 타워/병사가 담당.
3. 존은 가격이 점점 오르는 순서 해금 (5 → 15 → 20 → 25 → 30).
4. 적 처치 시 코인이 길에 흩어지고 자동 획득.
5. 중간 보스(대형 몹)로 긴장감을 주고, 마지막에 성문/마을 확장으로 마무리.
