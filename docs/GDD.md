# Last Town — 기획서 (Kingshot 벤치마킹, v0.1)

## 1. 컨셉
모바일 중세 영지 경영 + 병력 육성 + PvP/동맹 전략 게임. 킹샷(Kingshot)의 "가볍게 시작해서 깊게 빠지는" 초반 경험을 벤치마킹하되,
세계관·캐릭터·명칭·아트는 **독자 IP**로 제작한다(앱스토어 심사/저작권 리스크 회피).

## 2. 벤치마킹 포인트
| 영역 | 킹샷의 특징 | 우리 적용 |
|---|---|---|
| 코어 루프 | 건설 → 자원 → 병력 → 전투 → 성장 | 동일 구조, 프로토타입에 구현 |
| 병종 상성 | 보병/기병/궁병 삼각 상성 | 보병>궁병>기병>보병 (x1.5/x0.67) |
| 시간 기반 진행 | 건설·훈련 타이머, 오프라인 생산 | 구현(오프라인 최대 8시간) |
| 성 레벨 제한 | 성 레벨이 다른 건물 상한 | 구현 |
| 영웅 | 수집·성장 | v0.3 |
| 동맹 | 지원/협동/영토 | v0.4 (서버 필요) |
| 월드맵/PvP | 실시간 맵 | v0.5 |
| 수익화 | 인앱결제, 광고 가속 | 아래 §5 |

## 3. 코어 루프
1. 자원(식량·나무·돌) 자동 생산 → 창고 상한(성 레벨 비례)
2. 자원으로 건물 업그레이드(단일 건설 슬롯, 시간 소요)
3. 병영에서 병종 훈련
4. PvE 스테이지 출전 → 보상(자원·금)
5. 성 레벨 상승 → 상한/생산량 증가 → 반복

## 4. 프로토타입 범위 (v0.1, 이 저장소)
- 건물 5종(성/농장/벌목장/채석장/병영) Lv1~10
- 시간 기반 건설·훈련 큐, 오프라인 생산
- 삼각 상성 자동전투, PvE 20스테이지
- 로컬 저장(PlayerPrefs)
- 순수 C# 코어(`Assets/Scripts/Core`, Unity 비의존) + 런타임 uGUI(`Assets/Scripts/UI`)
- EditMode 테스트(`Assets/Tests/EditMode`)

## 5. 수익화 (후속)
- 가속 아이템, 건설 슬롯/VIP 패스, 월간 카드, 보상형 광고(가속 -N분)
- 초반 튜토리얼 구간은 결제 압박 없이 빠른 성취감 제공

## 6. 로드맵
