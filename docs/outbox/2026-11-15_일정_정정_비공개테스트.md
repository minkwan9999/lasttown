# 일정 정정 (사용자 답변 반영)

- 사용자 답변: 개인 계정이 오래전(2023-11-13 이전으로 보임)에 만든 계정이라 12명·14일 비공개 테스트 의무가 없음.
- 조사한 제3자 자료상 이 의무는 2023-11-13 이후 생성된 개인 계정 대상. 사용자 계정 생성일·면제 여부는 이 세션에서 확인 불가 → Play Console의 "프로덕션 액세스" 안내 화면에서 최종 확인 필요.
- 일정 영향: 이전 제안서의 단계 F(최소 14일)는 필수가 아님. 합계 약 8~11주 → 약 5~8주(아트 직접 제작 시 변동 큼).
- 재미 검증은 의무와 별개로 필요하므로, 선택적 소규모 비공개/내부 테스트(5~12명, 7일 정도)는 유지 권장. 기준 수치는 이전 보고서(결정사항_및_설치차단)의 기본안 사용.
- Unity 설치는 여전히 대기(PC 연결 방식 (a)/(b)/(c) 선택 필요).
