# MVP 제안 (2026-11-15) — 저장소 minkwan9999/lasttown, 브랜치 claude/festive-noether-ffucdo

## 0. 현재 상태
- Unity 코드(코어 로직·런타임 UI·EditMode 테스트 6개)는 작성·푸시 완료. **컴파일·실행·테스트는 한 번도 못 함**(이 환경에 Unity/C# 컴파일러 없음). 컴파일 가능 여부 = 확인 불가.
- 아트·사운드·튜토리얼·서버·결제는 없음. 현재는 텍스트 버튼 UI.

## 1. MVP 범위 (공개 가능한 최소)
| 우선 | 기능 | 상태 |
|---|---|---|
| P0 | 건설/자원/훈련/삼각 상성 PvE (코어 루프) | 코드 있음(미검증) |
| P0 | 튜토리얼(첫 10분 안내) + 퀘스트 보상 | 없음 |
| P0 | 자체 아트/UI(독자 IP) | 없음 |
| P0 | 인앱결제 상품 3~4종 + 복원 | 없음 |
| P1 | 영웅 3~5명(수집·강화, 전투 보너스) | 없음 |
| P1 | 일일 출석/보상형 가속(광고 없이 시작 가능) | 없음 |
| P1 | 분석 이벤트(튜토리얼 이탈, D1/D7) | 없음 |
| 뺄 것 | 서버·동맹·채팅·월드맵 PvP·랭킹·다국어·연구 트리·이벤트 | v2 이후 |

핵심 판단: 킹샷 재미의 상당 부분(동맹·월드맵)은 서버가 필요하지만 MVP에서는 빼고, **싱글 PvE 성장 루프의 재미와 결제 의향**만 먼저 검증한다.

## 2. 순서와 예상 분량 (1인 + AI 보조, 대략치)
1. 코드 컴파일 검증·버그 수정·UI 정리: 1~2일
2. 튜토리얼 + 퀘스트: 3~4일
3. 영웅 시스템(소수): 3~4일
4. 아트/사운드(구매 에셋 or 자체 제작, 독자 IP): 1~2주(가장 큰 변동)
5. 인앱결제 + 가속 아이템 + 분석: 3~5일
6. 비공개 테스트(TestFlight 등) → 지표 확인 → 심사 제출: 1~2주(심사 소요는 확인 불가)
합계 대략 5~7주. 근거 약한 추정이며 아트 수급 방식에 따라 크게 변함.

## 3. 인앱결제 최소 구조
- 팔 것(소비성/비소비성): ①건설·훈련 가속 패키지 ②자원 팩 ③건설 슬롯 +1(영구) ④월간 카드(매일 보상) ⑤광고 제거(광고 쓸 경우). 첫 구매 보너스 팩 1종.
- 원칙: 결제 안 해도 끝까지 진행 가능, 대기 시간 단축·편의만 판매. 초반 튜토리얼 구간은 결제 압박 없음.
- 결제 없이 재미 먼저 검증: (a) 결제 기능 빼고 TestFlight 소규모 배포, (b) 상점 화면에 "구매 의향 버튼"(가짜 문 테스트)으로 클릭률만 측정, (c) 지표 기준 예: 튜토리얼 완료율, D1/D7 리텐션, 세션 길이. 기준 수치는 사용자 합의 필요.
- 구현: Unity IAP(또는 StoreKit) + 영수증 검증. 서버 없이 시작하면 클라이언트 검증만 가능해 위변조에 취약 → 수익이 커지면 서버 검증 필요. 서버 없는 영수증 검증 수준의 충분성 = 확인 불가.

## 4. 플랫폼 후보
| | iOS 앱(Unity) | 웹(HTML5/WebGL) |
|---|---|---|
| 필요한 것 | Apple Developer 계정(유료), Mac+Xcode, 번들ID, 개인정보처리방침, 연령등급, 스크린샷, 앱스토어 심사 | 호스팅, 도메인, 결제 PG(웹 결제 연동) |
| 장점 | 목표(앱스토어)와 일치, IAP 표준 | 배포·테스트 즉시, 심사 없음 |
| 단점 | 심사·수수료, Mac 필요(이 환경 불가) | 모바일 게임 수익화 약함, Unity 웹 성능·로딩 부담, 앱스토어 아님 |
| 수수료·가입비 현재 금액/조건 | 확인 불가(최신 약관 확인 필요) | 확인 불가 |
| 심사 기간/거절 리스크 | 확인 불가(독자 IP면 IP 거절 위험 낮춤) | 해당 없음 |
| 사용자 PC에 Unity·Mac 있는지 | 확인 불가 | 해당 없음 |

추천: 비공개 검증은 TestFlight(iOS)로. Mac/Apple 계정이 없다면 먼저 웹 빌드로 재미만 검증하는 우회도 가능(확인 불가: 사용자 환경).

## 5. 법·IP
- 킹샷/Century Games의 이름·로고·캐릭터·텍스트·에셋 사용 금지. 기능 구조(건설·병종 상성 등 일반 장르 문법)만 참고. 임시명 Last Town은 상표 검색 전(확인 불가).
