# MVP 제안 v2 — 안드로이드(Google Play) 기준
저장소 minkwan9999/lasttown / 브랜치 claude/festive-noether-ffucdo. 이전 문서(2026-11-15_MVP_제안.md)의 범위·결제 상품 구성은 유지하고, 플랫폼·일정·검증·설치 항목만 갱신. iOS 안은 폐기.

## 1. 일정 (안드로이드, 1인+AI 보조, 대략치)
| 단계 | 내용 | 기간 |
|---|---|---|
| A | Unity 설치(아래 §3) + 컴파일 검증·버그 수정 + Android 빌드(APK 실기 테스트) | 2~3일 |
| B | 튜토리얼 + 퀘스트 | 3~4일 |
| C | 아트/사운드 | 1~2주(변동 최대) |
| D | Unity IAP(Google Play Billing) + 가속 아이템 + 분석 이벤트 | 3~5일 |
| E | Play Console 준비: 개발자 계정, 스토어 등록정보, 개인정보처리방침, 데이터 보안/콘텐츠 등급 설문, AAB 업로드 | 2~3일 |
| F | 비공개 테스트: 테스터 12명 이상 **연속 14일** 옵트인 유지 | 최소 14일 (테스터 모집·실패 시 재시작 포함 시 3~4주) |
| G | 프로덕션 액세스 신청 → 심사 → 출시 | 확인 불가(보통 며칠~1주+ 로 알려져 있으나 공식 수치 미확인) |
합계 대략 8~11주. F 구간 동안 B~D 개선 빌드를 계속 올릴 수 있으나, 테스터 이탈 방지를 위해 A~D 완료 후 F 시작 권장. 개인 계정 12명·14일 조건의 최신 여부 = 확인 불가(아래 출처는 제3자 블로그 중심, Google 공식 문서 미확인).

## 2. 재미 검증 = 안드로이드 비공개 테스트
- 테스터 12명 이상 모집(지인·커뮤니티·테스터 모집 서비스; 서비스 이용은 비용·품질 확인 불가).
- 측정: 튜토리얼 완료율, D1/D7 리텐션, 평균 세션 길이, 첫 건설/첫 전투 도달 시간, 상점 "구매 의향 버튼" 클릭률. 기준 수치는 사용자 합의 필요.
- 한계: 12명은 통계적으로 작고 지인 편향이 있어 "재미 확정"이 아니라 "치명적 문제 탐지"용. 결제 의향은 라이선스 테스터(테스트 결제)로 흐름만 확인, 실제 지불 의향은 소규모 공개 후 확인.
- 조직 계정(D-U-N-S)은 이 의무가 면제된다고 알려져 있음(확인 불가: 최신 조건·사용자 해당 여부).

## 3. Unity 설치 — 설치 전 승인 요청 항목 (설치하지 않음)
조사 근거: Unity 공식 Android 의존성 문서(아래 링크). 사용자 PC에 Unity Hub 없음(상위 세션 전달, 이 세션에서 확인 불가).
| # | 항목 | 내용 | 확인 상태 |
|---|---|---|---|
| 1 | Unity Hub | 설치 + Unity 계정 로그인 | 설치 용량 확인 불가 |
| 2 | Unity 에디터 | Unity 6 LTS 계열(6000.x). 프로젝트 파일은 임시로 6000.0.30f1로 표기됨 → 설치할 정확한 최신 LTS 패치 버전은 확인 불가(Hub 화면에서 확인 후 ProjectVersion.txt 맞춤) | 확인 불가 |
| 3 | 모듈: Android Build Support | 필수 | 공식 문서 |
| 4 | 모듈: Android SDK & NDK Tools | 필수. 6000.0+ NDK r27c 요구(에디터 버전별 상이할 수 있어 설치 버전 문서 확인 필요) | 공식 문서 |
| 5 | 모듈: OpenJDK | 필수. 6000.0+ JDK 17 | 공식 문서 |
| 6 | 패키지(프로젝트 내) | Unity IAP(com.unity.purchasing) 추가, 호환 버전·Play Billing 최소 버전 = 확인 불가 | 확인 불가 |
| 7 | 라이선스 | Unity Personal 사용 가능 여부·수익 한도 조건 = 확인 불가(최신 약관 확인) | 확인 불가 |
| 8 | 디스크/RAM | 에디터+Android 모듈 필요 용량 = 확인 불가(수십 GB 가능성) | 확인 불가 |
| 9 | 기기 | 안드로이드 실기기 + USB 디버깅(없으면 에뮬레이터, 성능 한계) | 사용자 보유 여부 확인 불가 |
| 10 | Google Play Console | 개발자 계정 등록(일회성 등록비 있음, 금액 확인 불가), 본인 인증 | 확인 불가 |
| 11 | 타깃 API 레벨 | Play 정책상 요구 수준은 연도별 상승 — 현재 값 확인 불가, 빌드 전 Google 문서 확인 | 확인 불가 |
이 중 설치/가입/결제는 모두 사용자 승인 후에만 진행. 이 문서는 승인이 아님.

## 4. 아트 (한 줄)
구매 에셋: 빠르고 품질 안정적이나 라이선스(상업·재배포 조건) 확인 필요하고 다른 게임과 비슷해 보일 수 있음 / 직접 제작: 독자성·IP 안전하지만 기간·인력 부담이 커서 일정 변동의 최대 원인. MVP는 구매 에셋 + 최소 자체 제작(로고·아이콘) 혼합을 권장하되 미정(사용자 결정).

## 5. 법·IP
킹샷/Century Games의 이름·로고·캐릭터·텍스트·에셋 미사용. 임시명 Last Town 상표·Play 중복 이름 검색 전(확인 불가).

사용자 답변 필요: ①§3 설치 항목 승인 여부(Unity Hub·Unity 6 LTS·Android 모듈) ②안드로이드 실기기 보유 여부 ③Play 개발자 계정 보유 여부·개인/조직 ④아트 방식 ⑤재미 검증 통과 기준 수치 ⑥이후 코드 commit·push 승인 여부
