# 사용자 결정 반영 + Unity 설치 상태 (사용자가 화면에서 직접 답변)

## 확정
- 플랫폼: 안드로이드(Google Play), 개인 개발자 계정(비공개 테스트 12명·14일 조건 대상일 가능성 높음, 최신 조건 확인 불가)
- 실기기 보유, 아트는 직접 제작(일정 §C 늘어날 수 있음), 코드 commit·push 사용자 승인

## Unity 설치: 차단됨
- 사용자가 F드라이브 설치를 승인했으나, 이 세션은 클라우드 Linux 컨테이너라 사용자 PC의 F드라이브에 접근할 수 없음. 연결 가능한 PC 폴더 목록이 비어 있음(list_computer_folders 결과 없음) → 설치 미실행.
- 해결 방법: (a) 사용자가 PC에서 Claude 데스크톱 앱 Remote Control로 폴더를 공유해 이 세션에 연결, 또는 (b) 사용자가 Unity Hub를 직접 설치(F드라이브 지정: Hub 설정 ▸ Installs ▸ Install Location)하고 모듈 3종 선택, 또는 (c) PC에서 도는 총괄 에이전트가 설치 수행.
- 설치 항목: Unity Hub, Unity 6 LTS(정확한 패치 확인 불가), Android Build Support + SDK&NDK Tools + OpenJDK.

## 재미 검증 기본안 (기준을 모르겠다는 사용자 답변에 대한 제안; 업계 통용 대략치, 근거 문서 확인 불가)
12명 기준이라 비율보다 인원 수로 판단:
- 튜토리얼 완료: 12명 중 9명 이상
- 다음 날 재접속(D1): 5명 이상 / 7일차(D7): 2~3명 이상
- 평균 첫 세션 5분 이상, 상점 구매 의향 버튼 클릭 2명 이상
- 미달 시: 이탈 지점(튜토리얼 단계별 로그)을 보고 개선 후 재테스트. 통과 기준은 사용자가 조정 가능.

## 사용자가 할 일
- 위 설치 방법 (a)/(b)/(c) 중 선택
- 검증 기준 기본안 수락/수정
